# CampusGear — CSE Laptop Finder

**Find the right laptop for your next big idea.**

CampusGear is a responsive laptop discovery and learning website designed to help students and creators compare laptops by use case, understand processor specifications, explore laptop hardware, and find manufacturer and retailer information in one place.

## ✨ Features

### 1. Laptop discovery and comparison
- Browse a curated selection of laptops from popular manufacturers.
- Explore laptop options by brand, budget, and search term.
- Review key buying specifications such as processor, RAM, storage, display, graphics, and intended use.
- Use the buying guide to understand common laptop configurations.

### 2. Laptop recommendations by use case
Explore laptop recommendations and specification guidance for:

- **CSE Students:** programming, web development, databases, IDEs, and everyday college work.
- **Gaming:** dedicated graphics, cooling, high-refresh-rate displays, and gaming performance.
- **Editing:** photo editing, video editing, rendering, and creative applications.
- **AI, 3D & Engineering:** heavier workloads, GPU acceleration, memory, and performance-oriented configurations.

Recommendations are guidance, not a guarantee that every laptop will suit every workload. Check the exact model configuration before purchasing.

### 3. Festive and Diwali offers
A promotional area highlights festive shopping campaigns and links to retailer or manufacturer offer pages.

Offer availability, discount amounts, bank benefits, exchange values, and validity dates can change. Always confirm the final offer, seller, stock, and checkout price on the destination website before ordering.

### 4. Laptop hardware learning lab
Learn how the main parts of a laptop work together, including:

- Keyboard and other input devices
- CPU and instruction processing
- RAM and temporary working data
- SSD and long-term storage
- GPU and graphics processing
- Display and visual output

### 5. Intel vs AMD Ryzen processor learning
Understand processor families and common laptop CPU suffixes, including:

- Intel Core processor families
- AMD Ryzen processor families
- H, HX, HS, U, and P suffixes
- Performance, power efficiency, and workload considerations

The learning section is intended to explain concepts. Actual performance depends on the exact processor, laptop cooling, power limits, memory configuration, and software.

### 6. Upcoming laptop and release watch
A dedicated section can highlight announced or upcoming laptop models and their features, with links to official manufacturer information where available.

A model may be announced before it is available to buy. Check its launch status and India availability before treating it as a purchasable option.

### 7. Manufacturer and retailer links
The website provides navigation to popular laptop brands and retailers so visitors can verify specifications, prices, warranty details, and availability at the source.

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `campus_laptop_finder_cse_india.html` in a modern browser.

Or use a local development server in the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/campus_laptop_finder_cse_india.html
```

## 🌐 Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload the website HTML file.
3. Rename it to `index.html` (recommended for the default GitHub Pages entry point).
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site.

Your website will be available at a URL similar to:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

Replace the placeholders with your GitHub username and repository name.

## 🔄 Prices, Offers, and Data Accuracy

Laptop prices and promotions are time-sensitive and can vary by:

- Date and time of checking
- Seller and marketplace
- PIN code and delivery location
- Bank/card, exchange, student, or coupon eligibility
- Stock and checkout-specific offers
- Exact model number and hardware configuration

**Important:** The standalone HTML page does not independently fetch live prices or automatically update its catalogue. Treat displayed sample or indicative prices as reference information, not guaranteed current prices. Verify the exact SKU, seller, final checkout price, warranty, and return policy on the linked retailer or manufacturer page.

A separate weekly research workflow may be used to review current India-market prices and newly announced laptop models. That workflow does not automatically modify this HTML file or publish changes to GitHub. To show updated information on the live site, update the website's data/content and push the changes to the repository.

## 🛒 Laptop Buying Checklist

Before buying, check:

- [ ] Exact model number and processor generation
- [ ] Minimum 16 GB RAM for a strong general CSE experience; check upgradeability
- [ ] 512 GB SSD or higher, depending on storage needs
- [ ] Display quality, brightness, resolution, and refresh rate
- [ ] Battery life and charging options
- [ ] GPU requirements for gaming, editing, AI, or 3D workloads
- [ ] Cooling and sustained performance
- [ ] Keyboard, webcam, ports, and build quality
- [ ] Warranty, service availability, return policy, and seller reputation
- [ ] Final checkout price after eligible offers
